# num3d
Memperkenalkan Matematika yang memberikan semua kemungkinan solusi untuk Axioma: (-1)^(1/2) memiliki solusi ortogonal terhadap garis skalar real.

# Num3D - 3D Algebra

**English:** This library introduces a 3D power-associative algebra where the square root of -1 has a full 2D plane of solutions orthogonal to the real scalar line. It features 4 distinct multiplication operators: `*` (analytic), `>>` (Z3 cyclic), `^` (quaternion cross), and `@` (vector rotation).
